# garlic

Second home box: ThinkPad T61, Ubuntu Server 24.04, wired `192.0.2.51` (static),
Wi-Fi `192.0.2.101` (DHCP fallback), tailnet `100.64.0.30`. Runs the second Pi-hole
and the home Forgejo (`origin` of the AI-Brain vault and of this repo).

Unlike Serverus there is no `collect.sh` snapshot here: the install scripts are the source
of truth and write the live files themselves. Each script refuses to overwrite a live file
that differs from what it would write, so drift shows up on a re-run.

## scripts/ (run on garlic with sudo, in this order)

| Script | Writes | Notes |
|---|---|---|
| `install-pihole-garlic.sh` | `/opt/pihole/docker-compose.yml`, resolved drop-in `no-stub.conf`, `/etc/resolv.conf` link | Same image as Serverus. `misc.dnsmasq_lines` (the `home.example.com` wildcard) is set by `FTLCONF_` here because the API refuses it: change it by hand when it changes on Serverus. |
| `install-nebula-sync-garlic.sh` | `/opt/nebula-sync/docker-compose.yml`, root-600 `.env` (passwords typed, never stored here) | Serverus is primary. Selective sync, `RUN_GRAVITY=false`. Use Serverus's web login password, not its app password. |
| `install-forgejo-garlic.sh` | `/usr/local/bin/forgejo`, `/etc/forgejo/app.ini`, `forgejo.service` | v15 LTS, SHA256 + GPG checked. Listens on all addresses (3000 web, 2222 SSH). `[migrations] ALLOWED_DOMAINS` = butter, needed for the push mirror. |
| `install-restic-garlic.sh` | `/root/.config/restic/*` (secrets typed/generated at run time), `/usr/local/bin/restic-backup.sh`, `restic-backup.service` + `.timer` (05:45 UTC) | Daily backup to butter's rest-server (user/repo `garlic`): `sqlite3 .backup` of Forgejo's DB + restic of `/etc`, `/opt`, `/usr/local/bin`, `/var/lib/forgejo`, `/home/k`. Needs the Tailscale grant garlic → butter `tcp:8000` and the htpasswd user on butter first. Card #63. |

Not in a script: netplan (holds the Wi-Fi password), sshd hardening drop-in, lid switch,
Tailscale, unattended-upgrades. Steps and state are in the vault (Homelab Ideas, garlic).

## tools/

- `setup-forgejo-garlic-key.sh`: runs on **Serverus**: deploy key, `forgejo-garlic` ssh
  alias and verified host key for pushing the vault to garlic.
- `check-pihole-teleporter.sh`, `check-pihole-config-sync.py`: one-off diagnostics from the
  nebula-sync setup (session type / 403 on export; which config keys the replica rejects).

## Forgejo on garlic

- Vault `admin/AI-Brain`: push mirror to butter, `ssh://git@100.64.0.20:2222/admin/AI-Brain.git`,
  SSH key generated by Forgejo (deploy key with write on butter), on every push + every 8h.
- `admin/homelab` (this repo): pushed from Serverus (deploy key `serverus`, repo-local
  `core.sshCommand`), push mirror to butter `ssh://git@100.64.0.20:2222/admin/homelab.git`,
  same settings as the vault.
- Forgejo pushes with `StrictHostKeyChecking=accept-new` into the `git` user's
  `~/.ssh/known_hosts`: butter's key there must be RSA 4096
  `SHA256:<host-key-fingerprint>`.
- Tailscale policy: grant `garlic` → `butter` `tcp:2222`.
