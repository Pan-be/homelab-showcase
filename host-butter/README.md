# butter

Off-site box at a friend's: tailnet `100.64.0.20` only (no services on its LAN). Holds the
restic rest-server (backups of Serverus and garlic, one repo each, port 8000) and the off-site Forgejo: push-mirror target
for garlic's repos (this one and the AI-Brain vault). Since 2026-11-06 `origin` is garlic.

Like `host-garlic/`, the install script is the source of truth; there is no `collect.sh`.
It refuses to run if `/etc/forgejo/app.ini` or the unit already exists.

## scripts/ (run on butter with sudo)

| Script | Writes | Notes |
|---|---|---|
| `install-forgejo.sh` | `/usr/local/bin/forgejo`, `/etc/forgejo/app.ini` (640 root:git, secrets generated at run time), `forgejo.service`, system user `git`, data in `/var/lib/forgejo` | v15 LTS, SHA256 + GPG checked. Binds only to the tailnet IP: 3000 web, 2222 built-in SSH (system sshd on 22 untouched). ufw rules on `tailscale0` only if ufw is active. Creates admin `admin` with a random password printed once (must change at first login). Installed 2026-11-02 from this exact file (sha256 `c0273350…`). |
| `restic-hdd-copy.sh` | `/srv/restic-hdd/<repo>` | Install to `/usr/local/bin` (755). Run as `restic` by `restic-hdd-copy.timer` 07:00 UTC. Loops over `REPOS=(serverus garlic)`, skips a repo that doesn't exist yet, rsync `--ignore-existing`; ntfy on failure. |
| `restic-cloud-copy.sh` | B2 `<bucket>/<repo>` | Install to `/usr/local/bin` (755). Run as `restic` by `restic-cloud-copy.timer` 07:30 UTC. Same loop, `rclone copy --immutable`; healthchecks.io start/success/fail. |
| `restic-prune.sh [serverus\|garlic]` | prunes `/srv/restic/<repo>`, mirrors to HDD and B2 with deletions | Install to `/usr/local/bin` (750). Manual, `sudo`, repo password typed each time (one per repo). |

Not in a script: rest-server and its htpasswd users, the restic copy timers/units, Tailscale, BIOS boot order. Steps and state are in the vault
(Homelab Config Repo, Serverus Storage Layout).

## Forgejo on butter

- Host key (built-in SSH): RSA 4096 `SHA256:<host-key-fingerprint>`.
- Repos: `admin/homelab` and `admin/AI-Brain`, both push-mirror targets from garlic (deploy
  keys with write, generated by garlic's Forgejo).
- Tailscale policy: garlic → butter `tcp:2222` (mirrors), Serverus and garlic → butter `tcp:8000` (restic)
  and `tcp:2222`. Port 3000 is not granted to Serverus.
